# NearHackathon (Near Events)

Kickback-style event dApp for [nearhackathon.com](https://nearhackathon.com).

Guests put down an equal USDC deposit; people who show up split the pool.
Deposits arrive from any chain/asset via NEAR Intents / 1Click into a Rust
escrow contract on NEAR. Hosts are a Sputnik DAO plus a human co-host for
check-in.
