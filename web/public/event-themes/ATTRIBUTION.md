## Brand marks (2026-11-09)

Marks are bundled in `marks/` and shown small in the poster header and as a faint
watermark. They are trademarks of their owners; Nearvent uses them only to label
a theme the host chose, not to suggest endorsement. Check each owner's trademark
terms before using a theme in public marketing.

| File | Source |
|---|---|
| `marks/ethereum.svg` | [ethereum.org assets](https://ethereum.org/en/assets/) (diamond, rainbow) |
| `marks/bitcoin.svg` | [BitPay bitcoin-brand](https://github.com/bitpay/bitcoin-brand), CC0 |
| `marks/solana.svg` | Solana bars with the official purple-to-green gradient; official [branding page](https://solana.com/branding) was rate-limited when fetched, so geometry is the mark we already shipped |
| `marks/near.svg` | NEAR logo glyph from Simple Icons (CC0), colored `#00EC97` |
| `marks/claude.svg` | Claude mark from Simple Icons (CC0), colored `#D97757`; the Anthropic Brandfolder needs a browser session |
| `marks/openai.svg` | OpenAI mark from Simple Icons (CC0); openai.com/brand returned 403 to scripted download |
| `marks/gemini.svg` | Gemini star from Simple Icons (CC0) with the Google gradient colors |
| `marks/cursor.svg` | Cursor [brand kit](https://cursor.com/en-US/brand), cube 2D |
| `marks/github.svg` | [GitHub Brand Toolkit](https://brand.github.com/), Invertocat white |

Palettes follow each brand's published colors: Cursor `#14120B`/`#F7F7F4`, Claude
clay `#D97757`/ivory, ChatGPT green `#10A37F`, Gemini blue/purple/coral, GitHub
`#0D1117`/`#1F6FEB`/Copilot `#8534F3`, NEAR `#00EC97` on black, Solana
`#9945FF`/`#14F195`. Base, Grok and Hermes were not in the source list and are
unchanged. Codex now carries the OpenAI mark.

Unofficial sources in the request (Clawd mascot galleries, Claude Code wallpapers,
Bitcoin Wizard, third-party archives) were not bundled: their licenses are unclear.

AI visual references: [Claude / Anthropic](https://www.anthropic.com/legal),
[Codex / OpenAI](https://openai.com/academy/codex/),
[Cursor](https://www.cursor.com/brand),
[Grok](https://x.ai/legal/brand-guidelines), and

The app uses product names, palette cues and original textures; it does not
bundle their marketing screenshots or copied product illustrations.
