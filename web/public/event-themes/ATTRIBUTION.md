## Brand marks (2026-11-09)

Marks are bundled in `marks/` and shown small in the poster header and as a faint
watermark. They are trademarks of their owners; Near Me uses them only to label
a theme the host chose, not to suggest endorsement. Check each owner's trademark
terms before using a theme in public marketing.

| File | Source |

Palettes follow each brand's published colors: Cursor `#14120B`/`#F7F7F4`, Claude
clay `#D97757`/ivory, ChatGPT green `#10A37F`, Gemini blue/purple/coral, GitHub
`#0D1117`/`#1F6FEB`/Copilot `#8534F3`, NEAR `#00EC97` on black, Solana
`#9945FF`/`#14F195`. Base, Grok and Hermes were not in the source list and are
unchanged. Codex now carries the OpenAI mark.

Unofficial sources in the request (Clawd mascot galleries, Claude Code wallpapers,
Bitcoin Wizard, third-party archives) were not bundled: their licenses are unclear.
